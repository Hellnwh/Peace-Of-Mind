# PeaceMind Sanctuary: High-Fidelity Psychological Restoration

PeaceMind Sanctuary is an immersive, high-performance tele-health platform designed for ADHD, Anxiety, and Neuro-related wellness. It replaces clinical interfaces with a living, reactive sanctuary optimized for 60fps performance.

## 🚀 How to Deploy for Free (Firebase App Hosting)

To get your sanctuary "alive" and accessible to everyone, follow these steps:

### 1. Push to GitHub
First, initialize a git repository and push your code to GitHub:
```bash
git init
git add .
git commit -m "Deployment ready"
git remote add origin https://github.com/YOUR_USERNAME/peacemind-sanctuary.git
git push -u origin main
```

### 2. Set Up Firebase
1.  Go to the [Firebase Console](https://console.firebase.google.com/).
2.  Select your project.
3.  In the left sidebar, go to **Build > App Hosting**.
4.  Click **Get Started** and connect your GitHub repository.
5.  Select the `main` branch and the root directory.
6.  Firebase will automatically detect Next.js and set up a deployment pipeline.

### 3. Configure Domain
Once the build completes, Firebase will provide a free `web.app` or `firebaseapp.com` subdomain. You can also connect a custom domain for free.

## 🌟 Core Features

### 1. ADHD Care Suite
- **Reaction Focus**: Impulse control training game.
- **Simon's Echo**: Harmonic pattern memory recall.
- **Stroop Balance**: Inhibitory control challenge.
- **Zen Pomodoro**: Gamified productivity timer.
- **Memory Lanterns**: Working memory training.
- **Sand Scribble**: Tactile Zen garden with procedural audio.

### 2. Clinical Restoration
- **Scientific Screening**: Validated PHQ-9 and GAD-7 assessments.
- **Sonic Sanctuary**: Pure harmonic resonance using additive synthesis.
- **Moon Breath**: Cinematic guided breathing exercises.
- **Wellness Dashboard**: Real-time tracking of clinical scores and mood trends.

### 3. Ethical Safeguards
- **Local Safety Engine**: Instant detection of high-distress keywords.
- **Crisis Integration**: One-tap connection to AASRA, iCall, and emergency services.
- **Data Privacy**: All personal reflections are stored securely in your private Firebase Firestore profile.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Database/Auth**: Firebase (Firestore & Authentication)
- **Physics/Animation**: Framer Motion (60fps Optimized)
- **Audio**: Web Audio API (Multi-sampled & Additive Synthesis)
- **Styling**: Tailwind CSS + Shadcn UI (Glassmorphism)
